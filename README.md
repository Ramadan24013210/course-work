# Reminder & Event Calendar System

## Описание
Това е уеб система за управление на събития и напомняния.  
Потребителите могат да създават събития, да добавят напомняния и да ги организират в категории чрез календар.

## Основни функции
- Регистрация и вход в системата
- Създаване, редактиране и изтриване на събития
- Добавяне на напомняния
- Категории за събития
- Календар с преглед на събитията
- Търсене и филтриране

## Технологии
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- React или ASP.NET MVC
- JWT Authentication

Проектът е в процес на разработка и ще бъде добавен скоро.
